# Content briefs

One brief per CONTENT experiment. A brief exists so a page can be written without
inventing facts about the business.

**How to use one:** fill in every `[NEEDED: ...]` marker with a real fact. Anything
still marked NEEDED when drafting starts is a fact that must be confirmed, not
guessed. A page shipped with invented service scope, pricing, or client outcomes
is worse than no page — it misrepresents a real company and creates claims the
business has to honour.

Each brief declares one primary intent, its query cluster, and its checkpoint, so
the page is an experiment under spec section 10 rather than a publication.

Order is set by [`../docs/P2_PAGE_GATE.md`](../docs/P2_PAGE_GATE.md): deepen pages
that already own their intent, highest contract value first.
